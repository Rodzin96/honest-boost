Seu app está seguro — saiba o que fazer

Este guia explica por que o Windows pode mostrar um aviso e como prosseguir com segurança.

Por que o Windows mostra um aviso?

1

Windows SmartScreen

O Windows possui uma proteção chamada SmartScreen que verifica todos os arquivos executáveis baixados da internet. Quando um app é novo ou tem poucas instalações, o Windows exibe um aviso de "arquivo de origem desconhecida".

Isso não é um vírus. É apenas o Windows sendo cauteloso com apps que ele ainda não conhece.

2

Por que isso acontece com o Honest Boost?

Como somos um produto novo e em crescimento, o Windows ainda não tem dados suficientes para confiar automaticamente. Grandes empresas pagam caro por certificados de assinatura digital para evitar esse aviso — estamos trabalhando para obter o nosso.

3

Como verificar que é seguro

Você pode verificar a autenticidade do arquivo comparando seu hash SHA256 com o valor oficial abaixo. Se os valores coincidirem, o arquivo é legítimo e não foi adulterado.

Hash oficial (SHA256):
e9e96511bc5ea4b3dd9beedc91fc412842a62989fbc39d0c5ed02794b0317839

Como instalar

1

Baixe o instalador

Clique no botão "Iniciar download" na página de downloads após fazer login na sua conta.

2

Execute o instalador

Abra o arquivo HonestBoostSetup.exe que foi baixado. Se aparecer um aviso do Windows Defender:

warning Se ver "O Windows protegeu seu PC":
  1. Clique em "Mais informações"
  2. Clique em "Executar mesmo assim"
3

Instale normalmente

O instalador NSIS vai abrir. Siga as etapas na tela para concluir a instalação.

check_circle Pronto! Após instalado, o app abrirá automaticamente. Use sua key para autenticar.

Verificar hash manualmente (opcional)

Para verificar que o arquivo não foi corrompido ou adulterado:

terminal

No Windows PowerShell

Get-FileHash -Path "C:\Caminho\Para\HonestBoostSetup.exe" -Algorithm SHA256

O resultado deve ser: e9e96511bc5ea4b3dd9beedc91fc412842a62989fbc39d0c5ed02794b0317839
